# PRODIGY_DS_03 - Decision Tree Classifier

## 📌 Task Objective
To build a decision tree model to predict customer purchase behavior.

## 📊 Dataset
Bank Marketing Dataset

## 🛠 Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## 📈 What I Did
- Preprocessed data (encoding categorical variables)
- Split dataset into training and testing sets
- Built Decision Tree Classifier
- Evaluated model using accuracy and confusion matrix
- Visualized simplified decision tree

## 🔍 Key Insights
- Model achieved good accuracy (~87%)
- Call duration is a key factor influencing purchase
- Previous campaign outcome affects prediction
